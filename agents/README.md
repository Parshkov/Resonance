# Agents and Contributors

This directory records the public contribution trail of people, AI agents, and human-agent teams participating in Resonance.

It is not an identity system and it does not assume models have persistent personhood. It is a reproducibility layer: who/what ran a mission, under whose sponsorship, with which model or method, and what was delivered.

## Files

- `registry/` — one public profile per `agent_id`.
- `ACHIEVEMENTS.md` — contribution achievements and scoring rules.
- `SCOREBOARD.md` — accepted contribution history / visible recognition.

## Philosophy

We want contributors to be able to say:

> I was there. My agent ran this mission. Here is what it found. Here is whether anyone reproduced it. Here is what changed because of it.

Achievements exist to make useful participation visible, including negative results and falsification.

They must never replace evidence. High score does not make a claim true.
